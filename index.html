CZ X Cleaner Privacy Policy

Last updated: 2026

CZ X Cleaner does not collect, store, transmit, or share personal data.

All actions performed by the extension run locally within the user's browser and only on the user's own X account.

No account credentials, messages, posts, likes, replies, or other user information are sent to external servers.

The extension uses local browser storage only for user preferences such as language settings and saved usernames.

Data Collection

CZ X Cleaner does not collect personal information.

Data Sharing

No data is shared with third parties.
